## 1. PID 제어

### 1.1 기본 구조

PID 제어기의 전달함수:

$$C(s) = K_p + \frac{K_i}{s} + K_d s = K_p\left(1 + \frac{1}{T_i s} + T_d s\right)$$

- $K_p$: 비례 게인
- $K_i$: 적분 게인
- $K_d$: 미분 게인
- $T_i = K_p/K_i$: 적분 시간, $T_d = K_d/K_p$: 미분 시간

시간영역 제어입력:

$$u(t) = K_p e(t) + K_i \int_0^t e(\tau)\,d\tau + K_d \frac{de(t)}{dt}$$

### 1.2 각 항의 역할

| 항 | 역할 | 부작용 |
|---|---|---|
| P | 현재 오차에 비례한 즉각 반응, 상승시간 감소 | 게인 증가 시 오버슈트 증가, 정상상태 오차 잔존(비적분계 기준) |
| I | 정상상태 오차 제거 (오차 누적) | 위상 지연 유발 → 안정성 저하, 오버슈트 증가, windup 문제 |
| D | 오차 변화율에 반응, 예측적 제동 → 오버슈트 감소, 안정성 향상 | 노이즈에 민감(고주파 증폭), 이상적 미분기는 비인과적(proper 아님) |

### 1.3 성능 지표

- **상승시간 (rise time)**: 최종값의 10~90% (또는 0~100%) 도달 시간
- **오버슈트 (%OS)**: $\%OS = e^{-\zeta\pi/\sqrt{1-\zeta^2}} \times 100$ (표준 2차 시스템 기준)
- **정정시간 (settling time)**: $T_s \approx 4/(\zeta\omega_n)$ (2% 기준)
- **정상상태 오차**: $e_{ss} = \lim_{s\to0} sE(s)$, 시스템 타입과 입력 형태(step/ramp/parabola)에 따라 결정

### 1.4 튜닝 방법

**Ziegler–Nichols (개루프, 계단응답법)**
S자형 개루프 응답에서 지연시간 $L$, 시상수 $T$(또는 반응률 $R=K/T$)를 구해 표에 따라 게인 설정. 1차+지연(FOPDT) 근사가 가능한 공정에 적용.

## 2. 근궤적법 (Root Locus)

### 2.1 정의와 근본 아이디어

폐루프 특성방정식

$$1 + KG(s)H(s) = 0$$

에서 게인 $K$를 $0\to\infty$로 변화시킬 때 폐루프 극점이 $s$-평면 상에서 그리는 궤적. 개루프 전달함수의 극점(K=0에서 시작점)에서 출발하여 영점(K=∞에서 도착점, 유한 영점이 부족하면 무한대)으로 이동하는 경로를 통해, 게인 선택에 따른 폐루프 안정성·과도응답 특성을 그래프로 파악하는 방법.

### 2.2 작도 규칙
- **가지 수**: 개루프 극점 수 $n$개만큼 궤적이 존재 (시작점 = 개루프 극점)
- **대칭성**: 실수축에 대해 대칭
- **실수축 상의 궤적**: 자신의 오른쪽에 있는 개루프 극점+영점의 개수(실수)의 합이 홀수인 구간
- **점근선(asymptote)**: 극점 수 $n$ − 영점 수 $m$개의 점근선이 존재
  - 각도: $\theta_k = \dfrac{(2k+1)180°}{n-m}$
  - 교차점(centroid): $\sigma_a = \dfrac{\sum p_i - \sum z_i}{n-m}$
- **이탈점/유입점 (breakaway/break-in point)**: 실수축 궤적이 갈라지거나 합쳐지는 점, $\dfrac{dK}{ds}=0$ 조건으로 계산
- **허수축 교차점**: Routh-Hurwitz 판별법으로 특성방정식의 계수를 이용해 임계 게인 $K_u$와 교차 주파수 산출 (Ziegler-Nichols 폐루프법의 이론적 근거)
- **각도 조건 / 크기 조건**:
  - 각도조건: $\angle G(s)H(s) = (2k+1)180°$ — 궤적 상의 점이 만족해야 하는 조건 (K와 무관)
  - 크기조건: $K = \dfrac{1}{|G(s)H(s)|}$ — 궤적 상의 특정 점에 대응하는 게인값 산출

### 2.3 근궤적과 과도응답의 연결

- 지배극점(dominant pole)이 실수축에서 멀어질수록(허수부↑) 진동 성분 증가, 감쇠비 $\zeta=\cos\theta$ ($\theta$: 극점과 원점을 잇는 선이 음의 실수축과 이루는 각)
- 등감쇠비선(constant $\zeta$ ray), 등고유주파수원(constant $\omega_n$ circle), 등정정시간선(constant $\sigma$ vertical line)을 근궤적 위에 겹쳐 그려 원하는 %OS·$T_s$ 사양을 만족하는 게인/극점 위치를 직접 선정 가능
- PID 게인 튜닝을 시간영역 사양(오버슈트, 정정시간) 기준으로 직접 설계하는 방법론(root locus design)의 기반

### 2.4 보상기 설계에의 활용

- **영점 추가**: 궤적을 좌측(안정 방향)으로 당김 → PD 제어기, lead 보상기의 역할과 대응
- **극점 추가**: 궤적을 우측(불안정 방향)으로 미는 경향 → 적분기(원점 극점) 추가는 정상상태 오차 개선을 위해 안정성 저하를 감수하는 트레이드오프 (PI 제어기)
- Lead/Lag 보상기의 극-영점을 근궤적 상에서 원하는 지배극점 위치를 지나가도록 배치하는 것이 근궤적 기반 설계의 핵심 절차

## 3. 주파수 응답 (Frequency Response)

### 3.1 정의

선형시불변(LTI) 안정계에 정현파 입력 $u(t)=A\sin(\omega t)$를 인가하면, 정상상태 출력은 동일 주파수의 정현파:

$$y(t) = A|G(j\omega)|\sin(\omega t + \angle G(j\omega))$$

즉 전달함수 $G(s)$에 $s=j\omega$를 대입한 $G(j\omega)$가 각 주파수에서의 이득(magnitude)과 위상(phase)을 결정. 시스템 식별(system identification)의 이론적 근거이기도 함.

### 3.2 보드선도 (Bode Plot)

- 크기: $20\log_{10}|G(j\omega)|$ [dB], x축은 $\omega$의 로그 스케일
- 위상: $\angle G(j\omega)$ [deg 또는 rad]
- 기본 요소별 점근선(asymptote):
  - 원점의 극/영점 $(j\omega)^{\pm n}$: 기울기 $\mp20n$ dB/dec, 위상 $\mp90n°$ (일정)
  - 1차 극 $1/(1+j\omega/\omega_c)$: 절점주파수 $\omega_c$ 이전 0 dB, 이후 −20 dB/dec, 위상 0°→−90°(절점에서 −45°)
  - 2차 극(감쇠비 $\zeta$): 절점주파수 근처에서 공진(peaking) 발생 가능 ($\zeta<0.707$), 기울기 −40 dB/dec
- 복합 시스템은 각 요소의 dB/위상을 합산(로그 스케일이므로 곱셈이 덧셈으로 변환)하여 작도

### 3.3 안정도 여유 (Stability Margins)

- **이득여유 (Gain Margin, GM)**: 위상이 −180°가 되는 주파수(위상교차주파수)에서 $1/|G(j\omega)|$, dB로는 $-20\log_{10}|G(j\omega_{pc})|$
- **위상여유 (Phase Margin, PM)**: 이득이 0 dB(1)가 되는 주파수(이득교차주파수)에서 $180° + \angle G(j\omega_{gc})$
- 일반적으로 PM이 클수록 감쇠비가 크고(근사식 $\zeta \approx PM/100$, PM<60° 범위에서 근사) 오버슈트가 작음
- 대역폭(bandwidth, $\omega_{BW}$): 이득이 −3dB(저역 대비)로 떨어지는 주파수, 응답속도(상승시간)와 반비례 관계

### 3.4 나이퀴스트 판별법 (Nyquist Criterion)

개루프 전달함수 $G(s)H(s)$의 나이퀴스트 궤적이 $(-1, 0)$점을 시계반대방향으로 감싸는 횟수 $N$과 개루프 RHP(우반평면) 극점 수 $P$, 폐루프 RHP 극점 수 $Z$ 사이의 관계:

$$Z = P - N$$

폐루프가 안정하려면 $Z=0$, 즉 $N=P$가 성립해야 함(개루프가 안정하면 $P=0$이므로 감싸는 횟수가 0이어야 함). Bode 선도로 얻기 어려운 다중 교차·불안정 개루프 계의 안정성 판별에 사용되며, 이득여유·위상여유의 이론적 근거가 됨.

### 3.5 주파수영역 보상기 설계

- **Lead 보상기** ($\frac{s+z}{s+p}$, $z<p$): 위상을 앞서게 하여(양의 위상 기여) 위상여유·대역폭 증가 → 응답속도·안정성 개선. 최대 위상선행 발생 주파수 $\omega_m=\sqrt{zp}$
- **Lag 보상기** ($z>p$): 저주파 이득을 높여 정상상태 오차 감소, 고주파 이득 억제(노이즈 감쇠). 위상은 지연되므로 위상교차주파수 이전에 영향이 끝나도록 배치
- **Lead-Lag**: 두 목적(응답속도 + 정상상태 정밀도)을 동시에 달성

### 3.6 PID·근궤적·주파수영역의 연결

- I항: 저주파에서 이득을 무한대로 밀어올림(적분기 특성, −90° 위상 기여) → 정상상태 오차 제거, 단 위상여유 감소 요인. 근궤적 관점에서는 원점에 극점을 추가하는 것과 동일 → 궤적이 우측으로 밀리는 트레이드오프
- D항: 고주파에서 이득 증가, +90° 위상 기여(위상선행 효과) → PD는 lead 보상기와 유사한 역할. 근궤적 관점에서는 좌반평면에 영점을 추가 → 궤적을 좌측(안정 방향)으로 당김
- 따라서 PID ≈ lag(적분) + lead(미분)를 결합한 보상기로 해석 가능하며, 이는 근궤적 상의 극-영점 배치와도 동일한 현상을 다른 좌표계(s-평면 vs. $j\omega$축 위 이득·위상)에서 보는 것
- 세 관점(시간영역 Z-N 튜닝, 근궤적 기반 극점 배치, 주파수영역 PM/GM 설계)은 동일한 폐루프 특성방정식 $1+KG(s)H(s)=0$을 다루는 서로 다른 표현일 뿐 — 이 등가성을 이해하는 것이 핵심
