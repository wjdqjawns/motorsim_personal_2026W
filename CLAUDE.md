# prj_motor_sim

Motor modelling, closed-loop simulation and parameter/friction identification (DC + PMSM dq/abc FOC). See README.md (Korean).

- Python: use `py -3.13` (plain `python` is the Windows Store alias). Run via `py -3.13 run.py <cmd> -c config/x.yaml`.
- Tests: `py -3.13 -m pytest tests -q` (~30 s). Keep them passing.
- Layout follows the user's thermoviz convention: `core/` (motor-independent engine), `domains/<type>/` (plugins with
  `<type>_schema/_model/_control/_ident.py`), `pipeline/` (registry/executor/runner/experiments/exporters), `utils/`.
  Use absolute imports (`from motorsim.core...`). New CLI commands: add `@command(...)` in pipeline/executor.py.
- Units SI, mechanical angle/speed. State arrays are (nx, N): everything is batched over N parameter sets.
- Plant params are a flat dict (motor + friction + load); friction stiction is `Tst` (Ts = sample time).
- Controller uses `control.nominal`; plant uses `motor.params` (deliberate mismatch).
- PMSM abc plant state is stator flux (psi_alpha, psi_beta); identification always works on dq signals (replay uses frame dq).
- Outputs go to `export/`. Large `.npz`/`.pt` files are regenerated by `dataset`/`train`.
